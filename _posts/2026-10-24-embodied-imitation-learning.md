> **机器人模仿学习的训练样本来自过去，部署时遇到的下一条样本却由自己的动作决定。** 理解这一点，才能解释为什么“验证集误差很小”与“连续完成任务”之间仍有距离。

{% include embodied-series.html %}

本文把“将杯子从桌面移动到托盘”作为贯穿例子。目标不是重复 [Diffusion Policy]({% post_url 2026-09-19-diffusion-policy %}) 的去噪推导，而是理解所有行为克隆策略共同依赖的基础：**训练的是什么条件分布、动作指令是什么意思、怎样收集真正有用的数据、怎样验证闭环能力**。

先修知识是概率期望、监督学习和基本反馈控制。读完后，应能设计一个从轨迹文件到闭环评估的最小实验，并判断模型失败是否真的需要更大的网络。

## 1. 一个学习样本究竟包含什么

### 1.1 状态、观测和历史并不相同

设环境真实状态为 $$s_t$$，动作是 $$a_t$$，则一次交互可以写为：

$$
s_{t+1}\sim P(\cdot\mid s_t,a_t),\qquad
o_t\sim O(\cdot\mid s_t).
$$

对于拿杯子，状态可能包含杯子位姿、接触状态、摩擦系数、关节位置与速度；相机图像和关节编码器只是其中一部分的观测。同一张图像可以对应“夹牢了”和“只是碰到了”，所以单帧图像通常不足以构成马尔可夫状态。

令历史为 $$h_t=(o_0,a_0,\ldots,a_{t-1},o_t)$$，任务指令为 $$g$$。策略实际学习：

$$
\pi_\theta(a_t\mid h_t,g).
$$

有限观测窗口、RNN 隐状态和 Transformer 缓存，都是对历史的压缩。是否足够，取决于任务：判断物体正在滑落可能需要短时运动信息；记住已经打开过哪个抽屉则可能需要更长记忆。

### 1.2 行为克隆是在拟合示范条件分布

轨迹数据集 $$\mathcal D=\{\tau_i\}_{i=1}^N$$ 给出专家在某些历史下选择的动作。最大似然训练是：

$$
\mathcal L_{\mathrm{BC}}(\theta)
=\mathbb E_{(h,g,a)\sim\mathcal D}
[-\log\pi_\theta(a\mid h,g)].
$$

固定方差的高斯策略会把这个目标化成加权平方误差。方差不是无关紧要的常数：以米为单位的位置误差和以弧度为单位的旋转误差，若直接相加，就隐含指定了两者的相对重要性。归一化和损失权重都属于问题定义。

BC 不需要奖励，但依赖示范质量。数据若混合多个操作者、不同速度和不同控制器，同一个输入对应的动作分布也会改变。模型输出不稳定时，需要先排除标签语义不一致。

## 2. 为什么单步准确不能保证长时间成功

### 2.1 训练分布和执行分布是两个对象

为简化符号，先假设状态可观测。记 $$d_\pi^t(s)$$ 为策略 $$\pi$$ 在第 $$t$$ 步访问状态的分布。BC 优化的是专家分布上的动作误差：

$$
\mathbb E_{s\sim d_E}[\ell(\pi(s),\pi_E(s))],
$$

但机器人运行时承受的是：

$$
\mathbb E_{s\sim d_\pi}[\ell(\pi(s),\pi_E(s))].
$$

专家拿杯子时几乎总能对准杯柄，模型稍微偏了一点后，下一张图像就可能不再属于示范中的典型状态。此后即使网络在原验证集上保持准确，也无法约束它在新状态下的行为。

### 2.2 一个误差累积上界的直觉推导

设任务长度为 $$T$$，策略在仍沿专家状态分布运行时，每一步错误概率至多为 $$\epsilon$$。用并集界，第 $$t$$ 步之前至少出错一次的概率至多为 $$\min(1,t\epsilon)$$。这里不需要假设每步错误相互独立。

假设一次错误可能使后续所有步骤都产生额外代价，且每步额外代价至多为 1，则：

$$
\Delta J\leq\sum_{t=1}^{T}\min(1,t\epsilon)
\leq\min\left(T,\frac{T(T+1)}2\epsilon\right).
$$

这个教学推导说明了最坏情形为什么可能出现 $$T^2\epsilon$$ 量级。它**不是每个机器人任务的实测增长规律**。如果低层反馈能迅速消除偏差，或环境天然把机器人带回稳定区域，上界会非常松。分布偏移的系统化处理可阅读 [DAgger 原论文][dagger]。

另一个容易混淆的量是“整条轨迹从未出错”的概率。在独立且恒定错误率的额外假设下，它是 $$(1-\epsilon)^T$$。它不是任务成功率：有些错误可恢复，有些成功任务也包含许多局部不精确动作。

### 2.3 长时程任务还受子任务组合影响

若任务依次要求找到杯子、抓起、运输、放下，整体成功率应按条件概率写成：

$$
P(S)=P(S_1)P(S_2\mid S_1)
P(S_3\mid S_1,S_2)P(S_4\mid S_1,S_2,S_3).
$$

不能直接把四个单独重置实验中的成功率相乘：单独测试抓取的初始状态，未必等于搜索模块结束时产生的状态。**模块交界处的状态分布**也是需要评估的对象。

## 3. DAgger 改变的首先是数据分布

DAgger 的关键不是换一种网络，而是让学习者访问状态，再由专家给这些状态标注动作，持续并入训练集。[Ross 等，AISTATS 2011][dagger]

一个概念算法如下：

```text
D ← 初始专家示范
repeat:
    π ← 在累计数据 D 上训练
    用当前策略或专家—学习者混合策略访问状态
    对访问到的状态询问专家正确动作
    D ← D ∪ 新的状态—专家动作对
选取独立闭环验证表现合适的策略
```

必须区分**谁执行动作**和**谁提供标签**。某一步由学习者执行，不代表要把它自己的错误动作当作专家标签。混合执行是控制采集分布的一种办法，标签仍需说明来源。

原理论需要在线学习、损失和可恢复性等条件；“增加纠错示范就一定把误差降为线性”并不成立。真实机器人里，专家可能无法对每个状态即时给出动作，人工接管还带有反应延迟。只标注接管区间是一种实际数据采集方案，不能自动继承完整 DAgger 的理论结论。

从工程角度看，接管记录至少应包含：触发时刻、开始生效时刻、接管前观测、人工动作、策略原始建议和控制模式。否则模型可能学到“失败后延迟半秒才纠正”，却被误认为学习速度不够快。

## 4. 动作空间定义决定了策略学到的控制接口

### 4.1 六个浮点数并不自动构成一个动作

同样一串六维数值，可以表示关节目标、末端绝对位姿、末端增量或空间速度。每种接口都需要写清楚：

| 属性 | 必须回答的问题 |
| --- | --- |
| 物理量 | 目标位置、位姿增量、速度，还是力矩？ |
| 坐标系 | 基座系、相机系、工具系，还是关节空间？ |
| 单位 | 米/毫米、弧度/角度、每秒量/每步量？ |
| 时间 | 指令在什么时刻生效，保持多长时间？ |
| 夹爪 | 开度、力目标、二值开合，还是归一化命令？ |
| 下层控制 | 插值、滤波、限幅、阻抗参数分别是什么？ |

例如工具系平移增量 $$\Delta p^E$$ 要执行为基座系目标，应使用当前姿态：

$$
p_{\mathrm{cmd}}^B=p_t^B+R_E^B\Delta p^E.
$$

不能直接把 $$\Delta p^E$$ 加在基座位置上。若采用完整位姿增量，左乘与右乘对应不同表达系；详见 [机器人运动学]({% post_url 2026-04-17-robot-kinematics %})。

### 4.2 动作与观测的因果对齐

假设相机曝光在 $$t$$，图像送达、推理、通信共延迟 $$L$$。策略产生的指令真正影响的是 $$t+L$$ 之后的状态。数据文件中的“第 100 帧”和“第 100 个动作”是否配对正确，取决于记录的是采样时间、发送时间还是执行时间。

以 20 Hz 指令频率为例，每步 50 ms；若延迟 100 ms，控制器实际面对的是至少两步以前的视觉信息。简单把动作标签整体平移两格，只能补偿固定延迟；随机抖动和不等频传感器需要时间戳、插值规则及有效帧掩码。

一个可靠的轨迹格式应保留 `episode_id`、传感器时间、命令时间和控制器模式。重采样是数据处理决策，原始时间戳应保留以便核对。

## 5. 动作块、时间集成与闭环频率

策略一次预测 $$H$$ 个未来动作：

$$
A_t=(a_{t\mid t},a_{t+1\mid t},\ldots,a_{t+H-1\mid t}).
$$

执行前 $$K\leq H$$ 个，再重新观测。$$H$$ 决定预测范围，$$K$$ 决定多长时间内不重新采纳视觉信息；推理耗时、并发方式和低层频率进一步决定真实反馈延迟。ACT 将动作分块和生成式模仿结合，并使用时间集成处理重叠预测；这里仅介绍接口意义，具体网络见 [ACT 原论文][act]。

{% include figure.html id="fig-embodied-action-timing" src="/assets/images/figures/embodied-action-timing.svg" alt="观测、推理延迟、预测动作块以及只执行前两个动作的时间轴" caption="动作时间轴教学示意：预测四步、执行两步。动作块覆盖范围与重新获取反馈的间隔是不同参数；实际时间还应计入推理和通信延迟。" size="full" width="960" height="460" source="本文绘制" %}

在同一物理时刻 $$t$$，不同起点的动作块会给出多个预测，可写成：

$$
\bar a_t=\frac{\sum_{j\in\mathcal I_t}w_j a_{t\mid t-j}}
{\sum_{j\in\mathcal I_t}w_j},\qquad w_j\geq0.
$$

这是一般加权形式，不指定某个实现如何定义新旧权重。集成能减小抖动，也可能推迟夹爪开合、把不同策略模式平均在一起。绝对目标可以平均，基于不同起点的相对增量则需先转换到共同参考；旋转还必须在合法表示上融合，不能平均两个旋转矩阵后直接发给机器人。

因此，动作块变长并不单调提高成功率。学习运输杯子的平滑轨迹需要连续性，杯子开始滑落时则需要及时的新反馈。

## 6. 数据划分与指标：防止把记忆当成泛化

### 6.1 先分轨迹，再切训练窗口

相邻图像高度相似。若把同一段轨迹随机拆成训练帧和验证帧，窗口甚至可能共享大部分内容，验证误差会显得非常好。正确顺序是按整条轨迹或更高层的采集组划分，再分别生成窗口。

需要跨物体泛化时，应按物体实例划分；需要跨操作者泛化时，应按操作者划分。只有一个物体的数据，即使切出很多轨迹，也不能回答新物体泛化问题。动作均值、标准差和视觉统计量只在训练部分计算。

### 6.2 把成功率拆成可诊断的指标

| 层面 | 建议观察 | 它不能单独证明什么 |
| --- | --- | --- |
| 离线拟合 | 按动作维度分解误差、夹爪事件时差 | 不能证明闭环完成任务 |
| 任务结果 | 成功率、完成时间、失败阶段 | 单个总数不能定位原因 |
| 恢复 | 指定偏移后的恢复率、重试次数 | 只对测试过的扰动有意义 |
| 执行 | 限幅比例、跟踪误差、推理时延分位数 | 小时延不意味着语义正确 |

每个条件记录成功次数与试验次数。若 20 次中成功 16 次，点估计是 80%，但样本很少；用 Wilson 方法得到的 95% 区间约为 58.4%—91.9%。这说明不能把 16/20 和 17/20 的差异轻易解释为确定改进。

训练停止点也应按固定验证规则选择，不能从测试集反复挑最好的一次。示范质量、网络选择与停止准则对机器人学习的影响，可参照 [robomimic 的原始研究][robomimic]；本文的评估表是面向学习实验的建议，不是该论文的原表。

## 7. 可运行小实验：同样拟合专家，为什么恢复不同

考虑二维状态 $$s=(x,y)$$，动作直接改变状态：$$s_{t+1}=s_t+a_t$$。任务是沿 $$y=0$$ 移动到 $$x=1$$。专家控制器为：

$$
a_x=0.2(1-x),\qquad a_y=-0.5y.
$$

但初始数据只包含 $$y=0$$ 的成功示范。对仿射策略做最小二乘时，横向增益无法由数据确定；最小范数解会令其为零。一旦给系统一个非零横向扰动，它就不知道如何恢复。

```python
import numpy as np

def expert(s):
    x, y = s
    return np.array([0.2 * (1.0 - x), -0.5 * y])

def features(states):
    return np.column_stack([states, np.ones(len(states))])

def fit(states):
    actions = np.array([expert(s) for s in states])
    return np.linalg.lstsq(features(states), actions, rcond=None)[0]

def rollout(weights, initial):
    s = np.array(initial, dtype=float)
    path = [s.copy()]
    for _ in range(20):
        s = s + np.r_[s, 1.0] @ weights
        path.append(s.copy())
    return np.array(path)

nominal = np.column_stack([np.linspace(0, 1, 21), np.zeros(21)])
w_bc = fit(nominal)
visited = rollout(w_bc, [0.0, 0.2])
# 在学习者访问到的偏离状态查询专家，而不是复用错误动作。
w_aggregated = fit(np.vstack([nominal, visited[:-1]]))
before = rollout(w_bc, [0.0, 0.2])
after = rollout(w_aggregated, [0.0, 0.2])
print(round(before[-1, 1], 6), round(after[-1, 1], 6))
# 0.2 0.0；后者真实值约为 1.907e-7，并非有限步严格为零。
```

这个实验刻意使用可辨识的线性专家和无噪声动力学。补充一轮标签后，仿射模型就能恢复真实增益；真实视觉任务不具备这样的简化条件。它证明的是**原数据没有约束横向恢复行为**，而不是 DAgger 在复杂机器人上一定一轮收敛。

## 8. 怎样开展一个有解释力的学习项目

先固定单物体、固定控制接口和清晰的成功判定，建立 BC 基线；再逐项改变条件：

1. 在相同数据与网络下比较单帧和短历史，检验部分可观测性。
2. 固定预测长度，改变实际执行长度，观察时延与恢复的关系。
3. 固定总采集预算，比较增加正常示范与增加纠错示范。
4. 先在训练分布测试，再分别改变物体、位置、光照和初始偏差。

若更长历史只改善开合事件，可能是记忆帮助识别任务阶段；若纠错数据主要改善受扰恢复，说明模型学到了数据原来缺失的局部行为。每次实验只改变一个主要因素，结论才有可追溯性。

## 9. 复习题与参考答案

**问题一：把同一批成功示范复制十遍，可以缓解分布偏移吗？** 不能增加状态覆盖。它可能改变优化过程，但没有提供偏离状态上的正确动作。

**问题二：动作归一化为什么不能在全数据上计算？** 这样会让训练过程获得验证或测试分布的信息；跨域实验里尤其可能掩盖真实的尺度变化。

**问题三：动作窗口从 16 变成 32，视觉反馈是否一定变慢？** 不一定。只有实际执行长度、推理耗时或调度方式改变，才会改变反馈时机。

**问题四：对同一张图像，示范动作一半向左、一半向右，最先检查什么？** 检查历史、任务指令、动作坐标和阶段是否缺失；确认确实存在合理多模态后，再选择能够表达多模态的策略。
